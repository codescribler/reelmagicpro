## Saved players

- Save player names and assign each player a unique keyboard letter. Profiles are available across all videos and projects on this computer.
- Press a player's letter while watching to bookmark their play. Choose their name in the Bookmarks dropdown to review their moments with the existing rewind, label editing and delete controls.
- Choose saved player names when adding or editing player tags, or enter a custom name without saving a profile.
- Edit or remove profiles from **Players**. Removing a profile preserves its existing bookmark lists and tag names.
- **B** remains the general bookmark shortcut. Player shortcuts are ignored while typing, choosing dropdown options, using dialogs or recording tracks.

## Download

Download **ReelMagic-Setup-0.9.0.exe** below to install or update ReelMagic on Windows. Existing installations can receive this version through the automatic updater: start the app, let the update download, then choose **Restart now** to finish installing it.
