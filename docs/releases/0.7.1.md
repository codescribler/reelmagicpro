## Improvements

When exporting a sequence as individual clips in **Both** formats, ReelMagic now creates separate **Standard** and **Instagram** subfolders inside the sequence's export folder.

Numbered filenames preserve the sequence order. Exporting a single format continues to save the clips directly in the sequence folder.

## Download

Download **ReelMagic-Setup-0.7.1.exe** below to install or update ReelMagic on Windows. Existing installations can also receive this version through the app's automatic updater.
