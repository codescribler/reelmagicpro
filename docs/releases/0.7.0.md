## What's new

- **Export a sequence as individual clips.** Choose Standard (landscape), Instagram, or Both, then choose where to create the output folder.
- Clips are saved in a folder named after the sequence, with numbered filenames that preserve the sequence order. Both formats get `_standard` and `_instagram` suffixes.
- Individual exports use each clip's own edits, framing, music and brightness settings.
- Repeat exports create a new numbered folder. Cancelling keeps completed files and shows where they were saved.

## Fixes

- Fixed landscape sequence exports freezing and becoming pixelated at joins between recorded zooms and static clips, particularly with 29.97 fps footage.

## How to use

Select your sequence, then choose **Export sequence → Individual clips → Standard, Instagram, or Both → Choose location**.
